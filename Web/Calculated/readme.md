# 🧩 CTF Web Challenge – Calculated Risk

## 📌 Kategori
Web Exploitation – PHP Code Injection 

---

## 🎯 Deskripsi
Website **PML Bank Loan Calculator** menyediakan fitur kalkulator pinjaman
untuk membantu nasabah menghitung estimasi cicilan mereka.

Developer telah menambahkan validasi input menggunakan **regex**
untuk mencegah penyalahgunaan.  
Namun, proses perhitungan masih dilakukan menggunakan fungsi PHP yang berbahaya.

Tugasmu adalah menganalisis mekanisme perhitungan tersebut,
menemukan celah keamanan, dan mengeksploitasinya
untuk mendapatkan **flag**.

---

## 🎯 Objective
- Menganalisis cara kerja kalkulator pinjaman
- Memahami validasi input yang diterapkan
- Mengeksploitasi kelemahan pada proses perhitungan
- Mendapatkan flag yang tersembunyi
