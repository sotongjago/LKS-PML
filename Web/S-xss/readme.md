# 🧩 CTF Web Challenge – XSS (Guestbook Feedback)

## 📌 Kategori
Web Exploitation – Cross-Site Scripting (Stored XSS)

## 🎯 Deskripsi
Website **Guestbook Feedback** menyediakan fitur buku tamu bagi pengunjung
untuk meninggalkan pesan.  
Admin secara rutin membuka halaman ini untuk membaca seluruh feedback.

Tugasmu adalah menemukan celah keamanan **XSS** dan memanfaatkannya
untuk mendapatkan **flag**.
