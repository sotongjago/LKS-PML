# 🧩 CTF Web Challenge – JWT Authentication

## 📌 Kategori
Web Exploitation – Authentication (JSON Web Token / JWT)

---

## 🎯 Deskripsi
Aplikasi web ini menggunakan **JWT (JSON Web Token)** sebagai mekanisme
autentikasi pengguna.  
Setiap user yang login akan mendapatkan token yang disimpan dalam cookie.

Namun, apakah implementasi JWT ini sudah benar dan aman?

Tugasmu adalah **menyalahgunakan kelemahan autentikasi JWT**
untuk mendapatkan akses **admin** dan mengambil **flag**.

---

## 🚩 Format Flag
LKSPML{JWT_BYPASS_AUTH_4DM1N}
